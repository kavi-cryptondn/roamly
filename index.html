# Roamly travel API setup This app uses three live data APIs on the backend: - Amadeus for flight and hotel offers - Frankfurter for EUR conversion - Open-Meteo for weather ## Important - Do not put API keys in the frontend. - If no provider credentials are configured, the app will show a graceful error rather than inventing a price. - Prices are provider-sourced only; the app does not estimate or fabricate them. ## Environment variables Set these in your shell or hosting platform before running: ```bash export AMADEUS_CLIENT_ID="your-amadeus-key" export AMADEUS_CLIENT_SECRET="your-amadeus-secret" export AMADEUS_BASE_URL="https://test.api.amadeus.com" # use production URL for live app export ALLOWED_ORIGIN="http://localhost:3000" export PORT=3000 ``` ## Running locally ```bash npm install npm start ``` Check: ```bash curl http://localhost:3000/api/health ``` Example flight search: ```bash curl "http://localhost:3000/api/flights?origin=JFK&destination=LHR&departureDate=2027-06-10&returnDate=2027-06-18&adults=1" ``` Example hotel search: ```bash curl "http://localhost:3000/api/hotels?cityCode=PAR&checkInDate=2027-06-10&checkOutDate=2027-06-13&adults=2&rooms=1" ``` Example weather query: ```bash curl "http://localhost:3000/api/weather?city=Kyoto&startDate=2027-06-10&endDate=2027-06-13" ``` ## Pricing rules - The app always keeps the original provider currency. - It converts to EUR only as an additional value. - If conversion fails, it shows `Price unavailable` instead of a made-up number. ## Notes This project is still a static app on GitHub Pages. The live API must be served from a Node-capable backend host, not from a static HTML file hosting service.
