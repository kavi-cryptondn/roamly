How prices work

Provider name and retrieval time are shown with results.

A result’s original provider currency is preserved. The EUR amount is a separate approximate conversion from Frankfurter. If a provider or exchange rate returns no price, Roamly says so instead of calculating one.

Weather is a forecast only for dates supported by Open-Meteo. If your dates are too far ahead, no forecast is substituted.
